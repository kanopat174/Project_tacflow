# TaxFlow — คำนวณและยื่นภาษีเงินได้บุคคลธรรมดาออนไลน์

เว็บแอปที่พา user เดินครบเส้นทางภาษีในที่เดียว: **ประเมินภาษี → วางแผนค่าลดหย่อน →
เตรียมเอกสาร → ยื่นแบบ 4 ขั้นตอน → ติดตามสถานะจนได้เงินคืน**

> โปรเจกต์เพื่อการศึกษา ไม่ใช่ระบบของกรมสรรพากร
> ตัวเลขอัตราภาษี ค่าใช้จ่าย และเพดานค่าลดหย่อนอ้างอิงเกณฑ์ภาษีเงินได้บุคคลธรรมดาจริง
> แต่ยังไม่มี backend — ข้อมูลผู้ใช้ แบบร่าง และประวัติการยื่นเก็บใน localStorage ของเบราว์เซอร์เท่านั้น
> ก่อนยื่นภาษีจริงต้องตรวจสอบประกาศของปีภาษีนั้นอีกครั้ง

- **Stack:** Vue 3 (`<script setup>`) + TypeScript + Vite + Pinia + Vue Router
- **โครงเว็บและ design system** อ้างอิงแนวทางเดียวกับโปรเจกต์ `astra-motors` (journey หลายหน้า,
  design tokens ชุดเดียว, ชั้นเรียก API แยกไฟล์, ระบบสมาชิก, toast)

## วิธีรัน

ต้องมี Node.js ^22.18.0 หรือ >=24.12.0

```sh
npm install
npm run dev        # เปิด http://localhost:5173
```

```sh
npm run build      # type-check + build production
npm run test:unit  # เทสต์เครื่องคำนวณภาษี (vitest)
npm run type-check # ตรวจ type อย่างเดียว
```

## เครื่องคำนวณ 6 หมวด

`/calculator` เป็นหน้ารวมหมวด แต่ละหมวดใช้ฐานภาษีและอัตราคนละชุดกัน จึงแยกหน้าและแยก engine กัน

| หมวด | เส้นทาง | ฐานภาษีและอัตรา |
|---|---|---|
| บุคคลธรรมดา | `/calculator/personal` | เงินได้สุทธิ → อัตราขั้นบันได 8 ขั้น (0–35%) |
| นิติบุคคล | `/calculator/corporate` | กำไรสุทธิทางภาษี → SME 0/15/20% หรือบริษัททั่วไป 20% หรือมูลนิธิ 2/10% ของรายได้ |
| เงินปันผลและดอกเบี้ย | `/calculator/dividend` | เทียบ "ภาษีหัก ณ ที่จ่ายเป็นภาษีสุดท้าย" กับ "นำมารวมคำนวณ + เครดิตภาษีเงินปันผล" |
| กำไรจากการขายหุ้น | `/calculator/capital-gains` | แยกกำไรที่ได้รับยกเว้นออกจากกำไรที่ต้องรวมคำนวณ |
| ภาษีมูลค่าเพิ่ม | `/calculator/vat` | ภาษีขาย 7% หักภาษีซื้อที่หักได้ → ยอดชำระหรือเครดิตยกไป (ภ.พ.30) |
| ภาษีหัก ณ ที่จ่าย | `/calculator/withholding` | ยอดก่อน VAT × อัตราตามประเภทเงินได้และประเภทผู้รับ |

**หมวดบุคคลธรรมดา** มีเครื่องมือเทียบการยื่นแบบของคู่สมรสด้วย เพราะอัตราภาษีเป็นขั้นบันได
การยื่นแยกจึงมักเสียภาษีน้อยกว่าเมื่อทั้งคู่มีเงินได้ แต่ถ้าคู่สมรสไม่มีเงินได้
การยื่นรวมจะได้ค่าลดหย่อนคู่สมรสเพิ่มอีก 60,000 บาท

**หมวดภาษีหัก ณ ที่จ่าย** เน้นจุดที่ผิดกันบ่อยที่สุด คือฐานที่ใช้หักต้องเป็นยอดก่อนภาษีมูลค่าเพิ่มเสมอ
ระบบถอด VAT ออกให้เองเมื่อผู้ใช้กรอกยอดที่รวมภาษีมาแล้ว

**หมวดเงินปันผล** คำนวณเครดิตภาษีเงินปันผล = เงินปันผล × อัตราภาษีนิติบุคคล ÷ (100 − อัตรา)
แล้ว gross-up เข้าไปในเงินได้ ก่อนเทียบภาระภาษีรวมทั้งปีของสองทางเลือก
โดยหลักคือถ้าขั้นภาษีของผู้ถือหุ้นต่ำกว่าอัตราภาษีนิติบุคคลของบริษัทผู้จ่าย การนำมารวมคำนวณจะคุ้มกว่า

**หมวดกำไรจากการขายหุ้น** แยกสี่ก้อน — หุ้นไทยในตลาดหลักทรัพย์และหน่วยลงทุนกองทุนรวมไทย (ยกเว้นภาษี),
หุ้นไทยนอกตลาด (เงินได้ตามมาตรา 40(4)(ช)), และหุ้นต่างประเทศ (เสียภาษีตามจำนวนที่นำเงินเข้าไทย
พร้อมเครดิตภาษีต่างประเทศไม่เกินภาษีไทยของก้อนนั้น)

## ออกเอกสารเป็น PDF

ทุกหมวดเครื่องคำนวณและหน้าติดตามสถานะมีปุ่ม **บันทึกเป็น PDF** ที่ออกใบสรุปการคำนวณแบบ A4

ระบบใช้กลไก print ของเบราว์เซอร์ (`window.print()` + `@media print`) แทนไลบรารีสร้าง PDF
เพราะไลบรารีอย่าง jsPDF ต้องฝังฟอนต์ไทยเองซึ่งทำให้ไฟล์ใหญ่และตัดคำผิด
ส่วนเบราว์เซอร์เรนเดอร์ภาษาไทยถูกต้องอยู่แล้ว และผู้ใช้เลือก "บันทึกเป็น PDF" ได้จากกล่องพิมพ์

เอกสาร (`src/components/TaxDocument.vue`) ถูก teleport ไปไว้ใต้ `<body>` เพื่อให้ตอนพิมพ์
ซ่อนทั้งแอปด้วย `display: none` ได้ ไม่เหลือหน้ากระดาษว่างต่อท้ายจากเนื้อหาที่ซ่อนไว้

## ตรรกะภาษีที่ระบบคำนวณให้

อยู่ใน `src/services/` ทั้งหมด เป็นฟังก์ชันบริสุทธิ์จึงเขียนเทสต์ตรวจได้

### บุคคลธรรมดา — `taxEngine.ts`

1. **หักค่าใช้จ่ายแบบเหมาตามประเภทเงินได้** — 40(1)/40(2) หัก 50% เพดานรวมกัน 100,000 บาท,
   40(3) 50% เพดาน 100,000, 40(4) หักไม่ได้, 40(5)/40(6) 30%, 40(7)/40(8) 60%
2. **ตัดเพดานค่าลดหย่อนทีละชั้น** — เพดานรายการ → เพดานตามสัดส่วนเงินได้ (เช่น กองทุนสำรองเลี้ยงชีพ 15%,
   RMF/SSF 30%) → เพดานรวมของกลุ่ม (กองทุนเพื่อการเกษียณ 500,000 บาท, ประกันชีวิต+สุขภาพ 100,000 บาท)
3. **เงินบริจาค** — บริจาคเพื่อการศึกษา/กีฬา/โรงพยาบาลรัฐ หัก 2 เท่า ไม่เกิน 10% ของฐานหลังหักค่าลดหย่อน
   แล้วจึงหักบริจาคทั่วไปไม่เกิน 10% ของยอดที่เหลือ
4. **ภาษีตามอัตราขั้นบันได 8 ขั้น** (0% – 35%) พร้อมแจกแจงเงินได้และภาษีของแต่ละขั้น
5. คืนค่า **อัตราภาษีที่แท้จริง** และ **ขั้นภาษีสูงสุดที่เงินได้ไปถึง** เพื่อใช้แนะนำการวางแผนลดหย่อน

## สมุดบัญชี — บันทึกรายรับรายจ่าย 6 โหมด

`/workspaces` สร้างสมุดได้หลายเล่ม แต่ละเล่มเลือกโหมดของตัวเอง
โหมดไม่ได้ต่างกันแค่ชื่อ แต่กำหนดทั้งหมวดรายการ ตัวชี้วัดที่แสดง และเกณฑ์ความเสี่ยง

| โหมด | เป้าออมต่อเดือน | เงินสำรองที่แนะนำ | ตัวชี้วัดพิเศษ |
|---|---|---|---|
| การเงินส่วนบุคคล | 20% | 6 เดือน | — |
| ฟรีแลนซ์ | 30% | 12 เดือน | ภาษีหัก ณ ที่จ่ายสะสม |
| ธุรกิจขนาดเล็ก | 15% | 12 เดือน | กำไรขั้นต้น, ภาษีมูลค่าเพิ่ม |
| บริษัท | 15% | 12 เดือน | กำไรขั้นต้น, ภาษีมูลค่าเพิ่ม, หัก ณ ที่จ่าย |
| นักลงทุน | 25% | 6 เดือน | — |
| เทรดเดอร์ | 20% | 12 เดือน | อัตราชนะ, profit factor, กำไรคาดหวังต่อไม้ |

เงินสำรองที่แนะนำต่างกันเพราะความผันผวนของรายได้ต่างกัน
มนุษย์เงินเดือนรายได้แน่นอนกว่าจึงสำรอง 6 เดือนพอ ส่วนฟรีแลนซ์และธุรกิจควรมี 12 เดือน

### วิเคราะห์ความเสี่ยงของรายจ่าย

ดูสองอย่างพร้อมกัน คือสัดส่วนรายจ่ายต่อรายรับ และเหลือเก็บถึงเป้าการออมของโหมดนั้นหรือไม่

ตัวอย่าง รายรับ 15,000 รายจ่าย 14,000 ต่อเดือน — รายจ่ายคิดเป็น 93.3% ของรายรับ
เหลือเก็บ 1,000 บาทหรือ 6.7% ซึ่งต่ำกว่าเป้า 20% ของโหมดส่วนบุคคล
ระบบจึงจัดเป็นระดับ **เสี่ยง** และบอกว่าต้องลดรายจ่ายอีกเดือนละ 2,000 บาท
ให้เหลือไม่เกิน 12,000 บาทจึงจะถึงเป้า

ระดับความเสี่ยงแบ่งตามสัดส่วนรายจ่ายต่อรายรับ — ไม่เกิน 50% ดีมาก, 50–70% ปกติ,
70–85% ควรเฝ้าระวัง, 85–100% เสี่ยง, เกิน 100% ขาดดุล

### วิเคราะห์เงินทุน

คำนวณจากเงินทุนคงเหลือหารด้วยเงินที่ไหลออกสุทธิต่อเดือน แล้วเทียบกับเกณฑ์ของโหมด

ตัวอย่าง เงินทุน 100,000 บาท รายจ่ายเดือนละ 10,000 บาท ไม่มีรายรับ — อยู่ได้ 10 เดือน
สำหรับโหมดส่วนบุคคลที่แนะนำ 6 เดือนถือว่า **ผ่านเกณฑ์**
แต่สำหรับฟรีแลนซ์ที่ควรมี 12 เดือน คิดเป็นเงิน 120,000 บาท จึงยัง **ขาดอีก 20,000 บาท**
คำตอบว่าเสี่ยงหรือไม่จึงขึ้นกับว่ารายได้ผันผวนแค่ไหน ไม่ใช่ดูตัวเลขเดือนอย่างเดียว

ระบบยังบอกวันที่เงินทุนจะหมดถ้ายังเผาในอัตราเดิม และถ้ารายรับมากกว่ารายจ่าย
จะรายงานว่าไม่ต้องเผาเงินทุนแทนการหารด้วยค่าติดลบ

### เป้าหมาย

ตั้งได้ 4 ชนิด ความคืบหน้าคำนวณสดจากรายการที่บันทึก

- **เก็บเงินให้ถึงเป้า** — นับเงินทุนตั้งต้นรวมกับยอดคงเหลือสะสม
- **รายรับต่อเดือน** — เทียบกับรายรับเฉลี่ยจากเดือนที่มีข้อมูลจริง
- **คุมรายจ่ายต่อเดือน** — สำเร็จเมื่ออยู่ใต้เพดาน และบอกส่วนที่เกิน
- **เงินสำรองให้อยู่ได้กี่เดือน** — ผูกกับเกณฑ์ของโหมดโดยตรง

## ธีมและการเข้าถึง

- **ธีมมืด** สลับได้จากปุ่มบน header ค่าเริ่มต้นตามการตั้งค่าของเครื่อง (`prefers-color-scheme`)
  และจำค่าที่ผู้ใช้เลือกไว้ใน localStorage — ธีมมืดเขียนทับเฉพาะ design token ไม่แตะ component style เลย
- **ลิงก์ข้ามไปเนื้อหาหลัก** โผล่ขึ้นมาเมื่อกด Tab ครั้งแรก ทุกหน้ามี `<main id="main-content" tabindex="-1">` รออยู่
- **ยอดสรุปที่เปลี่ยนแบบเรียลไทม์** ใช้ `aria-live="polite"` เพื่อให้โปรแกรมอ่านหน้าจอประกาศตัวเลขใหม่
- **กล่องยืนยันการยื่นแบบ** ปิดด้วย Escape ได้ และย้ายโฟกัสเข้าไปในกล่องเมื่อเปิด
- **ระหว่างโหลดข้อมูล** แสดง skeleton พร้อม `aria-busy` และข้อความ `sr-only` แทนการปล่อยหน้าว่าง
- ทุก animation ปิดอัตโนมัติเมื่อผู้ใช้ตั้งค่า `prefers-reduced-motion`

## ข้อจำกัดที่ยังต้องทำต่อ

- **ยังไม่มี backend** — `src/services/api.ts` จำลองด้วย localStorage การตรวจรหัสผ่านทำในเบราว์เซอร์
  จึงไม่ปลอดภัย ต้องย้ายไปฝั่งเซิร์ฟเวอร์ (เช่น FastAPI + PBKDF2 + bearer token แบบ `astra-motors`)
- **หน้าเอกสารเก็บเฉพาะ metadata** ยังไม่อัปโหลดไฟล์จริง
- **ยังไม่รองรับ** การยื่นรวมกับคู่สมรสแบบคำนวณสองแบบ, เงินได้ที่เลือกเสียภาษีแยก (ดอกเบี้ย/ปันผล),
  และมาตรการลดหย่อนชั่วคราวรายปี เช่น Easy E-Receipt
- **สถานะแบบภาษีเลื่อนตามเวลาแบบจำลอง** (submitted → received → reviewing → completed ภายใน 3 นาที)
  เพื่อให้เดโมเห็นการเปลี่ยนสถานะจริง

## การทดสอบ

```sh
npm run test:unit
```

**`taxEngine.spec.ts`** — อัตราขั้นบันไดทุกขั้น, เพดานค่าใช้จ่ายที่ใช้ร่วมกันของ 40(1)+40(2),
เพดานรวมกองทุนเกษียณ 500,000 บาท, เพดานประกันชีวิต+สุขภาพ 100,000 บาท, เพดานเงินบริจาค 10%
และการหักบริจาคเพื่อการศึกษา 2 เท่า รวมถึงกรณีขอบ เช่น เงินได้เป็นศูนย์และค่าติดลบ

**`corporateEngine.spec.ts`** — อัตราขั้นบันได SME, การตกไปใช้อัตรา 20% เมื่อคุณสมบัติไม่ผ่าน,
การบวกกลับรายจ่ายต้องห้าม, ผลขาดทุนยกมาที่ใช้ได้ไม่เกินกำไร และฐานภาษีของมูลนิธิที่ไม่ขึ้นกับรายจ่าย

**`investmentEngine.spec.ts`** — เครดิตภาษีเงินปันผลทุกอัตรา, จุดคุ้มทุนระหว่างสองทางเลือก
(ขั้น 25% ควรนำมารวมคำนวณ / ขั้น 30% ควรใช้ภาษีสุดท้าย), เพดานเครดิตภาษีต่างประเทศ
และการแยกกำไรหุ้นที่ยกเว้นออกจากกำไรที่ต้องเสียภาษี

**`vatEngine.spec.ts`** — บวก/แยก VAT และการ round-trip กลับได้ค่าเดิม, ภาษีซื้อต้องห้าม,
เครดิตยกไปเดือนถัดไป และยอดขายที่ได้รับยกเว้นซึ่งไม่นับรวมในเกณฑ์จดทะเบียน

**`withholdingEngine.spec.ts`** — ฐานที่ใช้หักต้องเป็นยอดก่อน VAT, อัตราของทุกประเภทเงินได้,
ดอกเบี้ยที่หักต่างกันระหว่างบุคคลธรรมดากับนิติบุคคล และแบบนำส่งที่ถูกต้อง

**`ledgerEngine.spec.ts`** — สรุปยอดและกำไรขั้นต้น, ค่าเฉลี่ยต่อเดือนที่คิดจากเดือนที่มีข้อมูลจริง,
เคสรายรับ 15,000 รายจ่าย 14,000 ที่ต้องออกมาเป็นระดับเสี่ยงพร้อมยอดที่ต้องลด,
เคสทุน 100,000 จ่ายเดือนละ 10,000 ที่ผ่านเกณฑ์ส่วนบุคคลแต่ไม่ผ่านเกณฑ์ฟรีแลนซ์,
เป้าหมายทั้ง 4 ชนิด และสถิติการเทรด

**`src/__tests__/smoke.spec.ts`** — เดินครบทุก route แล้วตรวจว่าไม่มี error/warning จาก Vue,
ไล่เส้นทางยื่นแบบตั้งแต่กรอกจนบันทึกสำเร็จ รวมถึงกฎ "หนึ่งปีภาษียื่นได้ครั้งเดียว"
ตรวจว่าเอกสาร PDF ของทุกหมวดถูกเรนเดอร์พร้อมยอดสรุป และตรวจธีมมืดกับ landmark สำหรับลิงก์ข้ามเนื้อหา

> (เบราว์เซอร์จริงไม่ต้องทำอะไร)
